# VibeCoding
Develop an internet-accessible landing page without writing code in an IDE.

---

## Primer prompt:
Quiero que me hagas una landing page muy visual y moderna, usando HTML, CSS y JavaScript vanilla (sin frameworks).

Estilo minimalista, limpia, elegante y muy fluida. Los colores gris oscuro y rojo deben ser predominantes, con blanco como color complementarios. Tipografía moderna y clara.

Los coches de Fórmula 1 de 2026 deben ser los protagonistas de la web. Deben tener animaciones al hacer scroll, deslizándose hacia arriba, acercándose o cambiando de perspectiva según el scrolleo y / o el contexto de la sección de la web. Transiciones fluidas, debe dar gusto navegar por la web.

La landing page debe ser responsive, adaptándose correctamente a escritorios, tablets o smartphones.

El contenido de la web debe ser el siguiente. La landing page debe explicar de forma clara y visual los cambios entre la temporada de Fórmula 1 de 2025 y la nueva temporada 2026. Debe incluir:

Cambios en los coches:
- Nuevas dimensiones (más ligeros y compactos).
- Aerodinámica activa.
- Enfoque más eficiente y sostenible.
- Cambios en el reglamento
- Sustitución del DRS por el nuevo modo de adelantamiento basado en energía eléctrica (overtake / boost mode).
- Mayor protagonismo del sistema híbrido (reparto 50% combustión / 50% eléctrico).
- Uso de combustibles sostenibles avanzados.
- Cambios en el calendario
- Introducción del nuevo circuito urbano de Madrid (Madring) en 2026.
- Visualización atractiva del circuito con iconos o ilustraciones.
	
	Para ampliar el contenido, puedes recopilar información contrastada.
